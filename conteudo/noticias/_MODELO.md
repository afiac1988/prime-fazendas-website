MODELO — copie este arquivo, renomeie (ex: `2026-09-guia-do-car.md`) e escreva. Arquivos que começam com `_` são ignorados.

## Capa

Se a notícia é sobre um imóvel específico do portfólio, use uma foto real dele:
`/midia/imoveis/<fazenda>/<foto>.jpg`.

Para notícia editorial (mercado, jurídico, clima, etc. — sem imóvel específico), use uma das
fotos do banco de imagens livres em `conteudo/midia/editorial/` — são fotos de banco (Unsplash,
licença livre para uso comercial), escolhidas por qualidade e tema, para não reaproveitar fotos
de imóveis fora de contexto. Ver `conteudo/midia/editorial/LICENCAS.md` para a lista completa e
qual foto combina com cada categoria. Exemplo: `capa: /midia/editorial/mercado.jpg`.

O nome do arquivo vira o endereço: `2026-09-guia-do-car.md` → `/blog/2026-09-guia-do-car/`

## Como escrever

Texto normal vira parágrafo. Deixe uma linha em branco entre parágrafos.

- Item de lista
- Outro item

**Negrito** e *itálico* funcionam. [Links assim](https://primefazendas.com).

> Citação em destaque, para dar respiro no meio do texto.

### Subtítulos

Use `##` para seções e `###` para subseções. Não use `#` — o título do artigo já é o H1 da página.
